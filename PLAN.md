# План работ по PDF Creator Go

## Статус: в основном выполнено

### ✅ Выполнено

1. Миграция консольного/веб-приложения на Wails v2.
2. Перенос Go backend: конфигурация, чтение Excel, генерация PDF.
3. Реализация Wails bind-методов для взаимодействия UI и Go.
4. GUI редактор с визуальным позиционированием текстовых полей.
5. Оптимизация drag-and-drop:
   - `transform: translate3d(...)` вместо `left/top`;
   - `requestAnimationFrame` для обновления свойств;
   - убрано пересоздание DOM при начале drag.
6. Ресайз ширины поля мышкой за левую и правую границы.
7. Выбор выравнивания текста кнопками: ← / ↔ / →.
8. Автоподбор размера шрифта под ширину блока.
9. Предпросмотр и генерация всех PDF.
10. **Автоперенос текста по шаблону превью:**
    - удалён ручной разделитель строк;
    - добавлен чекбокс «Автоперенос по шаблону превью»;
    - маска разбиения строится по самой длинной записи и применяется ко всем записям столбца;
    - warnings для записей, не подходящих под маску.
11. Сборка релизов:
    - `PDFCreatorGo.app` для macOS arm64;
    - `PDFCreatorGo.exe` для Windows amd64.
